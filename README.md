## ❖・Introduction・❖

For this assignment, you will extend on the work from assignment 1 in which you plotted the dates from a CSV file onto a single x-axis. You will now need to plot a y-axis onto which you will plot the times listed in the included CSV file, effectively separating date and time. The end result will be a scatter plot of dates and times along two axes, x and y. The scaffold required to carry out this assignment is included here; you needn’t add any files.

---

## ❖・Requirements・❖

Observe all the requirements from the first assignment, and add the following:

* The height of your container should be at least 1200 pixels.
* Map midnight to the bottom of the y-axis, where it meets the x-axis, and noon to the top of the y-axis.
* Map each hour in the day with a small line onto your y-axis, totaling 24 lines.
* No libraries may be used; only `d3.js` is allowed.
* Style the visualization so it’s intuitive from a glance.

The end result should be a [scatter plot](https://en.wikipedia.org/wiki/Scatter_plot) of dates and time.
